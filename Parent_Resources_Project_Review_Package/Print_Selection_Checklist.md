# Print Selection Checklist

Use this checklist for each resource before it is printed or placed in the Parkdale Parent Resources area. Do not print or display anything until every applicable item is checked and Anna has signed off.

- [ ] Source is reliable (official/professional organization, not a blog or unverified site)
- [ ] Content is family-friendly
- [ ] Language is respectful
- [ ] No confidential child/family information
- [ ] Appropriate for early childhood setting
- [ ] Anna reviewed and approved
- [ ] Printed pages are short and readable
- [ ] Materials are placed respectfully in the parent resource area

## Notes

- Apply this checklist resource-by-resource using `Resource_Review_Table.md` as the starting list.
- Record Anna's approval decision per resource in `05_Final_Supervisor_Approval_Evidence/`.
- Only move an approved page into `03_Print_Selected_Pages_For_Anna_Review/` after every box above is checked.
