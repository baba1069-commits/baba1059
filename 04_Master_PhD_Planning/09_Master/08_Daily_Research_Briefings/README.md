# Daily Research Briefings

This folder holds academic daily research briefing notes (Markdown only) for Jiecheng's Master/PhD planning.

## Scope

- Allowed: academic briefing markdown files (e.g. `YYYY-MM-DD_Morning_Academic_Briefing.md`) covering research progress, reading notes, meeting summaries, and planning items.
- Not allowed: private documents, identification documents, receipts, OSAP/financial-aid files, immigration documents, or original internship evidence. Those must never be stored in this repository.

## Naming convention

- Daily: `YYYY-MM-DD_Morning_Academic_Briefing.md` for each daily entry so files sort chronologically.
- Weekly rollups go in the `Weekly_Summary/` subfolder, named `YYYY-MM-DD_to_YYYY-MM-DD_Weekly_Academic_Summary.md` (start date to end date of the week covered).

## Layer 3 rule (change-monitoring only)

Each daily briefing only reports *changes* since the previous briefing (website updates, deadline changes, scholarship changes, professor/program news, action items) — it does not rewrite the full research record. See the template in any existing daily briefing file.
