# Weekly Academic Summary

This subfolder holds weekly roll-ups of the daily Morning Academic Briefings — a short aggregation of what changed across the week, not a full re-research.

## Naming convention

`YYYY-MM-DD_to_YYYY-MM-DD_Weekly_Academic_Summary.md` (start date to end date of the week covered).

## Scope

- Allowed: academic summary markdown files aggregating that week's daily briefings (changes only — deadlines, scholarships, professor/program news, action items).
- Not allowed: private documents, identification documents, receipts, OSAP/financial-aid files, immigration documents, or original internship evidence.
