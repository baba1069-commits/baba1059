# 7-School Project Map (Layer 1)

Goal: before researching individual professors and their papers, first build a baseline eligibility/fit profile for each of the 7 target schools. A strong professor match is wasted effort if the program itself will not admit Jiecheng due to language score, GPA, or reference-letter requirements.

## Schools tracked

1. University of British Columbia (UBC)
2. University of Toronto — OISE
3. York University
4. Western University
5. University of Waterloo
6. McGill University or Queen's University
7. University of Alberta or University of Calgary

## Per-school file structure

- `README.md` — quick status snapshot (program name, status, next action)
- `YYYY-MM-DD_Official_Program_Requirements.md` — admission requirements pulled from the official program page
- `YYYY-MM-DD_Faculty_Research_Map.md` — relevant faculty and their research areas (Layer 2)
- `YYYY-MM-DD_Jiecheng_Fit_Analysis.md` — evidence-based fit analysis built only from that school's Official_Program_Requirements.md and Faculty_Research_Map.md (fit level, best-fit programs, faculty alignment, strengths, risks, missing information, next action — no invented eligibility claims)

## Cross-school summary

- `YYYY-MM-DD_Seven_School_Fit_Matrix.md` — single table comparing all 7 schools side by side (best program, fit level, key strength, key risk, professor alignment, next action). Update this with a new dated file whenever a Daily Briefing confirms a change that affects a row — do not silently overwrite the existing matrix.

## Workflow

1. Complete `Official_Program_Requirements.md` for all 7 schools first (Layer 1).
2. Only then move to `Faculty_Research_Map.md` (Layer 2 — professor/paper research).
3. Finish with `Fit_Analysis.md` to decide which schools are worth the full application effort.
4. Roll all 7 Fit Analyses up into the `Seven_School_Fit_Matrix.md` cross-school comparison table.
