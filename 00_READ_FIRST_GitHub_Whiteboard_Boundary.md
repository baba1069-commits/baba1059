# READ FIRST — GitHub Whiteboard Boundary

## Purpose

This GitHub repository is **Jiecheng's academic planning whiteboard** — a working space for Master's/PhD application research and ECE internship project organization. It is not a storage location for private documents, and it is not a decision-making authority. This file defines what Claude Code may and may not do here.

## 1. What Claude Code may edit

Claude Code may edit Markdown planning files in this repository.

## 2. Allowed content

- School-by-school research maps
- Faculty research maps
- Daily academic briefings
- Application trackers
- README files
- Public or semi-public planning notes (e.g., resource curation packages, project rationales)

## 3. Not allowed content

The following must never be stored in this repository, in any form:

- OSAP files
- Receipts
- Immigration files
- IDs
- Police check
- Original internship evidence
- Family documents
- Private school account screenshots

## 4. Sourcing rule for official information

Admission requirements, deadlines, tuition, program availability, language waiver rules, and reference rules must be based on **current official university sources**. Do not invent or assume these details.

## 5. Handling uncertainty

If information is unclear or could not be confirmed from an official source, mark it as **"Needs Verification"** rather than guessing or asserting it as fact.

## 6. Privacy boundary

Claude Code should not store private documents in this repository (see Section 3 for the explicit list).

## 7. Decision-making boundary

Claude Code should not make final application decisions for Jiecheng. Research, organize, and summarize evidence — the decisions belong to Jiecheng (and, for the internship project, to his supervisor where applicable).
